# ReadyGym 0.8.6 页面与动效调整

保留灰白底色、绿色强调和卡通教练，把页面重点转向“接下来做什么”和“顺利练完”。

## 页面

- 首页：按未建档、无计划、已排计划、未结束训练切换主卡。进行中的训练使用会话自身的标题、动作和已完成组数，不随当前计划改变。休息日显示“下一次训练”。
- 训练：动作名和当前组数固定显示；示范图可手动收起；当前未完成组有明确标记；完成热区至少 48dp。休息区在滚动区外，未休息时显示全程组数进度，避免计时条出现和消失时挤动组数表。默认仍为 30 秒，可延长或跳过。
- 聊天：资料文字保持稳定，仅确认按钮首次可用时轻提示一次。主动发送后跟随；等待回复时如果上翻阅读，保留阅读位置，并显示新回复入口。档案保存并在界面可读取后进入计划页。
- 计划：保存档案后显示明确的下一步；新档案可生成新草稿，采用前不会覆盖当前计划。档案变化立即清除旧草稿，取消并使旧生成请求失效。
- 统计：本周个人目标和真实完成次数先呈现；其他指标降低层级，排行榜和勋章后移。肌群计算规则按需展开，日期范围中文化；历史快捷入口打开独立记录页。
- 回顾：一次克制的完成反馈，展示已完成组、实际练过动作、记录时长与负重。提前结束不宣称全部完成。

## 动效

继续复用 `SunnyMotion` 的 200/300ms 与弹簧参数。同级页面短淡入，按页保存滚动和展开状态；切换动作轻淡入；完成或撤销一组即时写入，并给颜色过渡与触觉反馈。文字不持续闪动，卡片入场使用固定 24dp 距离。系统关闭动画时，新增过渡直接到位，功能不等待动画。

## 验证

新增回归覆盖首页状态、继续旧训练、周统计时区、档案到计划的导航、旧草稿与晚返回请求失效、聊天阅读位置、48dp 勾选及撤销、休息区边界稳定、部分完成总结。
