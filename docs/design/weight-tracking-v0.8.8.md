# 体重记录与趋势图

参考用户提供的 `refs/weight/weight-chart.jpg` 与 `refs/weight/target-weight.jpg`，在统计页本周训练指标下加入体重卡。

- 白色圆角卡、当前读数和日期、目标差额、绿色折线与面积、网格、金色目标虚线；点选数据点显示日期与体重，辅助功能提供上一条/下一条操作。
- 目标体重底部弹层支持直接输入、0.1kg增减、快捷0.5/1kg步进、白色圆形滑块与绿色保存按钮。称重弹层另可选今天或过去日期。
- 每个本地日期一条记录，同日保存覆盖；历史倒序，可修改体重或确认删除。目标可清除。支持30–250kg，一位小数。
- 档案体重只明确标记为填写值并用于输入预填，不生成虚构历史。单条记录只显示点，多个记录按真实日期距离连线；缺测日不补值。默认显示最近30次，历史入口保留全部记录。
- 趋近目标或远离目标用颜色和文字双重表达；未设目标时，增减只中性描述。称重不修改训练档案、计划或训练会话。

## 数据

`core/weight/WeightTracking.kt` 定义记录与数值规则；`data/WeightRepository.kt` 负责本地读写；`WeightViewModel.kt` 与 `WeightTrackingPanel.kt` 连接图表和弹层。

Room数据库从v1迁移到v2，仅新增 `weight_entry` 和 `weight_target`，重量用整数十分公斤保存。旧版所有表原样保留，禁止破坏性迁移。迁移回归使用归档v1 schema真实建库，验证旧JSON、历史、进行中训练和已完成组。

## 验证与截图

回归覆盖迁移、重启持久化、同日更新、删除、日期/数值边界、目标趋势与图形范围，以及真实UI→ViewModel→Room→图表的记录/目标/修改/删除闭环。
