# 聊天调整方案中的动作演示（0.8.12）

在聊天每套调整方案的变化说明下、查看方案按钮上方，直接播放新换入和新增动作的 GIF。展示动作名称、器械与对应训练日；一套方案中同一动作跨天只展示一次，多个动作横向滑动浏览，避免整周调整撑出过长卡片。仅改变重量或组次、移除动作时不额外展示演示。

从已校验草稿对应的本地动作库解析演示，优先 APK 自带 GIF，其他使用现有服务器 GIF 路径；不接受模型生成的图片地址。完整适配演示画面，加载中有提示，失败可重试，没有素材时明确说明。`ExerciseGifPreview.kt` 复用原肌肉动作详情中的 GIF 加载组件，两处共享实现。

播放和重试演示、选择和切换方案均不调用保存；仍需用户点击“确认采用这套调整”。不改聊天协议、计划保存事务、数据库结构、当前会话同步或已完成组记录。

验证记录见 `releases/ReadyGym-0.8.12-validation.json`，发布记录见 `releases/ReadyGym-0.8.12-published.json`。
