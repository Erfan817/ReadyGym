# 隐私与数据说明

本文是面向维护者与用户的说明，不是法律意见。App 内的实际告知文案应与本文第 2 节一致。

## 1. 数据分类与流向

| 数据 | 存储位置 | 是否离开设备 | 接收方 |
|---|---|---|---|
| 训练档案（年龄、身高、体重、目标、器械条件、身体状况） | 手机 Room 本地库 | 使用 AI 功能时按需发送给模型 | AI 网关（直连模式）/ 服务器 AI 代理（回落模式） |
| 计划版本、每组实际记录、体重记录、勋章、回访检查点 | 手机 Room / SharedPreferences | 否（除训练完成摘要） | — |
| 训练完成摘要（时间、组数、训练量、昵称） | 服务器 H2 | 是 | 自建 Spring Boot 服务（用于周榜） |
| 聊天内容 | 手机内存（不落库） | 是 | AI 网关 / 服务端 AI 代理（服务端只做内存转发，不落盘） |
| 语音录音 PCM | 手机内存；中转时在服务器内存 | 仅当中转时 | 讯飞听写（经服务器）或系统识别服务 |
| 器械照片 | 拍照识别时压缩到 ≤1280px/JPEG70 后发送 | 仅这一步 | AI 网关（视觉模型） |
| 意见反馈文字、填写的联系方式、App 版本/机型/系统 | 服务器 H2 | 是 | 自建服务；管理员面板可读取 |
| 设备 token | 手机 Keystore 加密保存；服务端只存 SHA-256 哈希 | 每次请求 | 自建服务 |

本地数据**不等于云端备份**：目前没有跨设备恢复档案、计划、训练记录和体重数据的完整功能。卸载 App 会丢失本地数据。

## 2. App 内告知同意模板

首次使用 AI 功能前展示，用户确认后才发请求：

> 为了给你排训练计划、回答训练问题，会把你填写的身体资料、当前计划和聊天内容发给 AI 服务处理；照片只在你主动使用「拍照识别器械」时发送，录到的语音只在按住说话时用于转文字。这些内容不会用来给你打广告。你可以随时不用这些功能，回到手动选择动作和键盘输入。继续表示你已了解并同意。

语音、拍照、反馈三个入口各自再给一次就近说明（不要只靠首次全局同意）。

## 3. 留存与删除

- 本地：档案、计划、训练记录、体重记录只存在手机；App 内可修改/删除体重记录，卸载 App 即删除全部本地数据。
- 服务端：训练摘要、反馈、设备记录、AI 调用计数存放在 VPS 的 H2 文件库。当前**没有**自动过期、匿名化或「删除我的数据」自助入口，需要时由管理员按设备删除。
- 语音 PCM 与照片都不在服务器落盘，只在内存中转。
- `.tmp-tools/tts.wav` 是用于验证语音链路的**真人语音样本**，属于内部测试素材，不随 APK 分发；使用前应取得说话人同意，并在验证结束后从分发物中移除。

## 4. 第三方共享清单

| 服务 | 收到什么 | 用途 |
|---|---|---|
| OpenAI 兼容 AI 网关（当前 PackyAPI，`deepseek-flash`） | 聊天内容、档案、当前计划、器械照片 | 生成回复、计划草案、器械识别 |
| 讯飞语音听写 | 语音 PCM | 语音转文字（仅系统识别服务不可用时） |
| 蒲公英 | App 安装包、版本信息、更新说明 | 分发与检查更新 |
| 自建 VPS（Spring Boot） | 注册昵称、训练摘要、反馈、语音 PCM（中转）、AI 代理回落时的聊天内容 | 排行榜、反馈、语音中转、AI 代理 |

## 5. 已知缺口（待补）

- 当前公网入口是**明文 HTTP**，上述传输可被嗅探；上 TLS 前不能声称「传输已加密」。
- 服务端没有自动留存期限、数据导出与删除接口；管理端 token 是长期静态值。
- 旧版 Foundation Demo 文档里的 `consent: true` / `/api/intake/sessions` 描述**不适用于当前 App**，不要照抄。
- 训练建议与动作说明未经专业训练或医疗认证；身体疼痛或存在医学限制时应停止并寻求专业帮助。
